# UrbanTrace AI Frontend Prototype

UrbanTrace AI is a city-wide traffic command center interface for multi-camera monitoring, vehicle search workflows, analytics, and incident response.

## Tech Stack

- React + Vite
- React Router
- Tailwind CSS
- JavaScript

## Available Routes

- `/` — Dashboard
- `/live-camera-network` — Live Camera Network
- `/vehicle-search` — Vehicle Search
- `/traffic-analytics` — Traffic Analytics
- `/alerts` — Alerts
- `/admin-panel` — Admin Panel

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
